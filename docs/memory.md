# 角色记忆与爱之屋

**日常记忆可以单独运行。** 使用 Luma 时，角色会从当前 DSH 档案读取自己可用的本地记录。需要在插件外按角色管理、同步和检索知识库时，再安装 Windows x64 版爱之屋（Love House），从插件内连接。爱之屋是单独下载的辅助程序。[爱之屋 Windows 发行页](https://github.com/myflww/love-house/releases/tag/v0.10.7rc1)

## 同一条偏好会去哪里

| 操作 | 0.6.0 桌宠版 | 工作室版 |
| --- | --- | --- |
| 单独运行 Luma，从已保留的记录回忆 | 支持 | 支持 |
| 自动整理每位角色自己的长期用户画像 | 依靠已保留的原记录 | 可按角色开启、查看、修改或忘记 |
| 删除一条工作后，在新私聊中沿用已经记下的偏好 | 无逐项删除工作及独立画像入口 | 开启自动画像并已形成偏好条目时可用 |
| 连接爱之屋 | 每位角色单独绑定，可补同步 | 每位角色单独绑定，可补同步 |

例如，你让陆弥「以后做校对先列改动，再附全文」。工作室版提取到这条偏好后，它会出现在陆弥自己的画像中。删除那次工作会移除来源记录。需要她以后也忘掉这条偏好，请到这位角色的记忆管理里移除画像条目。已经同步到爱之屋的外部副本可以在爱之屋内管理。

## 如何连接

1. 下载并解压对应的 **Windows x64** 包，启动 `LoveHouse.exe`，等它完成本地初始化。[爱之屋 v0.10.7rc1](https://github.com/myflww/love-house/releases/tag/v0.10.7rc1)
2. 在 Luma 的「爱之屋」面板点连接。使用自定义数据目录时，选中已有档案所在目录。
3. 在面板查看连接状态和各角色知识库。服务暂时离线时可继续聊天与工作，已绑定角色的待同步记录会在重新连接后补交。

## 验证记录

使用独立临时档案，分别加载 v0.6.0 桌宠版宿主和工作室版宿主。外部服务采用爱之屋 v0.10.7rc1 的实际 Windows 记忆控制器。检查私聊召回时，用隔离模型记录插件实际提交的输入。

- **无爱之屋。** 两版都能召回仍保存在本机的记录。工作室版开启自动画像后，写入工作偏好、删除该工作和原文、关闭并重开档案，本角色新私聊仍收到了这条偏好。另一角色的新私聊没有收到。
- **关闭自动画像。** 在新的对照档案重复同一操作。删除工作和原文后，新私聊没有收到该偏好。
- **连接爱之屋。** 八个角色库分别通过核验。服务收到记录，并能向对应角色返回相关内容。已同步的来源被删除后，工作室版改用该角色的本地召回，测试中没有再请求外部旧摘要。
- **中断并恢复连接。** 已绑定的外部服务断开后，一条新记录进入待同步队列。服务重开、重新连接后，队列归零，八个库仍然可用。

以上结果验证了存储、删除、角色隔离和模型可见的上下文。模型最终是否在某次回复中选用该偏好，还取决于提问和模型本身。

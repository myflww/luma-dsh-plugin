# Luma 使用手册

Luma 在 DeepSeek Harness Desktop 内提供办公室、伙伴卧室和联系人。新档从鲸鱼娘开始。选中她可以聊天或交办工作，抽到对应的卡片后可以邀请更多伙伴。

## 安装 0.6.0

首次使用 DeepSeek Harness Desktop 时，请先打开一次桌面客户端，让 DSH 建立桌面档案。Windows 安装器会通过该客户端的插件命令加载 Luma。在发行页下载 `Luma-DSH-0.6.0-Installer.zip`，解压后双击 `Install-Luma-DSH.cmd`。安装包自带更新，已有完整的 0.5.4、0.5.3、0.5.2、0.5.1、0.5.0 或 0.4.3 插件目录即可离线升级。[下载 0.6.0 安装包](https://github.com/myflww/luma-dsh-plugin/releases/tag/v0.6.0)

首次安装可用新版下载器从公开发行页取得基础分卷及更新包。以下命令适用于 Windows PowerShell。

```powershell
Invoke-WebRequest -UseBasicParsing https://github.com/myflww/luma-dsh-plugin/releases/download/v0.6.0/Get-Luma-DSH-Public.ps1 -OutFile .\Get-Luma-DSH-Public.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Get-Luma-DSH-Public.ps1
```

安装器在桌面 `Luma-DSH` 中创建新版本的独立目录，核对每个文件的 SHA-256，再通过 DSH 自身的 CLI 安装。重新打开 DSH，点侧栏的「Luma 办公室」。DSH 会引用该目录，请长期保留。

- **从旧版升级**　安装器会在桌面 `Luma-DSH` 目录中依次查找 `DesktopPlugin-0.5.4`、`DesktopPlugin-0.5.3`、`DesktopPlugin-0.5.2`、`DesktopPlugin-0.5.1`、`DesktopPlugin-0.5.0`、`DesktopPlugin-0.4.3` 和 `Luma-DSH-0.4.3-Windows.zip`。旧版存放在别处时，可在命令末尾添加 `-Base "D:\Luma\DesktopPlugin-0.5.4"` 或 `-Base "D:\Downloads\Luma-DSH-0.4.3-Windows.zip"`。
- **首次安装**　安装器从本仓库的 0.4.3 发布取得基础美术，再应用 0.6.0 更新。首次下载约 1.87 GB，包含分卷、合并 ZIP 与完整插件时，建议预留 6 GiB。
- **离线安装**　将 0.6.0 发布中的 `Get-Luma-DSH.ps1` 和 `Luma-DSH-0.6.0-Update.zip` 放在一起，再使用上面的 `-Base` 指定本地基础包。
- **手动添加**　运行安装器时追加 `-PrepareOnly`，然后从 DSH 的插件页添加生成的 `DesktopPlugin-0.6.0` 目录。使用 `-Directory "D:\Luma"` 可以更改输出位置。

如需退回上一个版本，保留旧目录，关闭 DSH，运行以下命令再重新打开 DSH。安装器会重新注册桌面的 `DesktopPlugin-0.5.4`。旧目录位于其他位置时，追加 `-Base "D:\Luma\DesktopPlugin-0.5.4"`。回退只切换插件程序，收藏和会话继续使用当前 DSH 档案。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Get-Luma-DSH-Public.ps1 -Rollback
```

## 拖动伙伴与桌面探头

工作室版的「员工列表」支持点击角色头像或名字进入卧室。后续名册界面也在此基础上提供「换装」和用量明细。场景底部的「换肤」用于切换房间主题。

按住伙伴直接拖动，松开后她会在可走的地面稍作停留，再接回自己的活动。在办公室里，把伙伴拖到亮起的工位后松手即可换座。选到另一位伙伴的工位时，两人交换位置，正在处理的任务会继续。

在窗口模式下，把伙伴拖过 DSH 的外边缘再松手，她会出现在鼠标所在的显示器。全屏或使用键盘时，在「员工列表」点「桌宠」也可以带她出来。把桌宠拖到屏幕左边或右边松手，可以看到她从边缘探头、停留，再缩回去。点击探出的部分可将她拉回桌面。右键选择「回到房间」或在员工列表点「回到场景」，她会按当前作息回办公室或卧室。到了睡眠时段，桌宠也会安睡。

## 场景和爱之屋快捷连接

在 DSH 左栏点「Luma 办公室」，房间会铺满独立页面。场景左上角的侧栏按钮可随时展开或收起 DSH。点「菜单」可前往联系、收藏、卡包商店、插件设置或返回 DSH。在联系、卡册、商店或设置的页头点「返回场景」，会回到刚才的房间。打开这些功能时，宿主侧栏保持原来的开合状态。场景内可切换办公室和伙伴卧室，管理已拥有的房间与衣装。窄窗口可拖动画面，点「查看全景」可一次看全房间。「隐藏场景按钮」可暂时只看场景。

点击场景左上角「爱之屋」，再点连接按钮。面板会核对本机爱之屋的服务版本和每位员工的独立记忆库。本版已验证爱之屋 0.10.7rc1。如果旧版正在使用同一数据目录，请先在爱之屋中正常退出，再在插件中启动新版。已有自定义数据目录可在连接面板中选择。Windows x64 辅助程序见[爱之屋官方发布页](https://github.com/myflww/love-house/releases/tag/v0.10.7rc1)。

## 从第一位伙伴开始

1. 新的 DSH 档案从鲸鱼娘、普通办公室、她的普通卧室和空卡册开始。她会按本地时间上班、午休、下班回家和就寝。到办公室后，每位伙伴会走到自己的工位，在电脑前敲键盘、阅读和核对工作。在卧室中，她们会走动、坐到电脑前，也会躺到床上看手机。进入任一空间都沿用同一份作息。
2. 在「联系」中点头像发消息。点右上角「•••」可以设置人格、选择模型服务、查看记忆或切换对话。个人聊天默认使用 DSH 会话。私聊中说「下次先给结论」即可告诉这位伙伴你的习惯，改口或在记忆库撤回都可以。已有两位入职伙伴后，可以选人建群，排定接力顺序，写明谁起草、谁审阅、谁汇总。在「API 服务」中可以为每位伙伴分别选择 DSH 已配置的服务、具体模型与可用的思考强度。自定义端点支持 Chat Completions、Anthropic Messages 和 Gemini，可以读取服务列出的模型，也可以手动填模型 ID。设置会用于该伙伴的私聊、单人派工和群聊发言。
3. 去卡包商店领取本地星币，购买并打开卡包。开出入职卡后，在开包结果中选择邀请，或到「卡牌收藏 → 伙伴与空间」选择想消耗的一张卡并确认。入职后即可在联系列表和 DSH「新会话」的预设中找到她。
4. 「伙伴与空间」也列出了各人的正版卡面和所属卡包。持有该角色的全部正版卡面，自动获得专属办公室与卧室。此后即使消耗卡片，已经取得的空间依然保留。历史开包可在商店的收支记录中回看。
5. 打开桌面上的爱之屋后，插件会通过本机连接为每位伙伴绑定各自的记忆库。爱之屋关闭时，新增的记忆先保存在本机，恢复连接后再同步。「聊天设置 → 记忆库」可查看状态与记录。要连接自建的云办公服务器，请查看发布包的 `cloud-office/README.md`。

想先邀请第二位伙伴，可以用 300 星币的新册礼挑选单角色卡包。晨光序章对应端木嫣，蓝蔷薇回响对应陆弥，月相典藏对应白霜命。龙妈妈、克劳德、吉米和绯洛的入职卡出自初见与远行。各卡包当前概率和具体可兑换版本都能在插件内查看。免费试拆可体验动画，持有卡来自实际购入并开启的卡包。

「我的卡册」只展示当前档案实际持有的卡。想了解各卡包的收录范围，可以切到「卡池图鉴」。已兑换的卡仍保留获取记录。在同一 DSH 档案更新插件会延续进度。切换到全新档案时，收藏与解锁从头开始。

在私聊、派工或群聊的输入框点「＋ → 添加图片或文件」。每条可附 4 个文件。Luma 不限制单个文件或整条消息的附件体积。实际可发送的大小取决于 DSH、服务商和所选模型。DSH 默认会话可使用文件工具处理文档。指定 DSH 模型时可发送文本和受模型支持的图片。自定义端点也支持将 PDF 交给兼容模型。选择全员接力时，每位参与伙伴都会收到这条消息的附件。

打开办公室或卧室的「员工列表」，在每位伙伴的「联系」按钮旁可直接查看距下一枚星币的用量进度。在「菜单 → 卡包商店 → 员工用量」可查看详细账本。用量按模型返回的记录计入对应伙伴。每人每满 100 万 token，钱包自动增加 1 星币，余量继续累计。旧档可回填能确认归属、且留有用量记录的 DSH 会话。独立 API 的用量从 0.5.3 起按服务返回的记录累计。旧版装帧商店已下架，升级后会按购买记录中的实付金额自动退还星币。

## 伙伴来信、隐私与版本更新

- 在「插件设置 → 日常陪伴」管理主动来信和房间弹幕。清醒且空闲的伙伴偶尔会发来私信，每天合计至多三条，点弹幕即可回复。默认使用本地角色对白，也可显式启用伙伴自己的 API 写信。
- 「屏幕使用情况」默认关闭。开启后可以预览最近 15 分钟的前台应用名和使用时长，再逐个选择能收到摘要的伙伴。摘要只随你主动发送的普通私聊交给所选伙伴的模型。关闭采集会清空本机临时记录。
- 0.6.0 桌宠版内置的更新检查沿用 GitHub CLI。发现新版本可以查看、稍后查看或跳过此版，也可在「插件设置 → 版本更新」中手动检查。自动检查使用已登录的 GitHub CLI，也可手动到公开发行页下载。安装更新时沿用原来的桌面档案。

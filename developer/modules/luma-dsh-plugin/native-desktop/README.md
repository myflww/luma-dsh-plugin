# Luma 星伴办公室

Luma 0.5.2 适用于 Windows 上的 DeepSeek Harness Desktop。安装器通过本机 DSH 的插件命令注册本目录。在 DSH 的「插件 → 添加插件 → 安装第三方插件」中选择包含本文件的目录并启用。以后打开 DSH，从侧栏进入「Luma 办公室」。DSH 会引用此目录，移动插件时需重新指定位置。

## 场景和爱之屋快捷连接

在 DSH 左栏点「Luma 办公室」，房间会铺满独立页面。场景左上角的侧栏按钮可随时展开或收起 DSH。点「菜单」可前往联系、收藏、卡包商店、插件设置或返回 DSH。在联系、卡册、商店及设置的页头点「返回场景」，会回到刚才的房间。场景内可直接切换办公室和伙伴卧室，管理已拥有的房间与衣装。窄窗口可拖动画面，点「查看全景」可一次看全房间。「隐藏场景按钮」可暂时只看场景。

点击场景左上角「爱之屋」，再点连接按钮。面板会核对本机爱之屋的服务版本和每位员工的独立记忆库。本版已验证爱之屋 0.10.7rc1。如果旧版正在使用同一数据目录，请先在爱之屋中正常退出，再在插件中启动新版。已有自定义数据目录可在连接面板中选择。下载见[爱之屋官方发布页](https://github.com/myflww/love-house/releases/tag/v0.10.7rc1)。

## 从鲸鱼娘开始

全新 DSH 档案只有鲸鱼娘和她的主题房间，打开「我的卡册」时持有卡片和已开卡包均为零。「卡池图鉴」可查看各包的收录范围。「办公室」显示当前班次，伙伴按本地时间在办公室或卧室活动。打开员工列表可找人、进入房间或发消息。换肤面板显示已获得且有对应美术的主题，可在「伙伴与空间」查看其他解锁条件。工作日 09:00–12:00 和 13:00–18:00 上班，中午在办公室休息。有待办时伙伴仍可留在工位。清闲时 20:00 就寝、06:00 起床。白天在卧室会自行走动，按自己的习惯在床边、书桌和休息区停留。

进入「卡包与装帧」，领取新册礼，用本地星币购买卡包，再到未开封卡包中拆包。得到可兑换的卡片后，可在开包结果中邀请该伙伴，也可以稍后到「卡牌收藏 → 伙伴与空间」办理入职。只有确认兑换时才消耗选中的一张具体卡片。每位伙伴的页面都列出对应卡包、可兑换版本与空间收集进度。集齐某位伙伴的全部正版卡面，可永久解锁她的专属办公室和卧室。免费拆包体验只用于预览。

## 联系与记忆

在「联系」选择已入职的伙伴，输入消息即可聊天。可以给一位伙伴派工，也可以选择多位已入职的伙伴建立协作群。每位伙伴分别保存设置与聊天记录。在对话设置中可调整人格、配置兼容 Chat Completions 的模型服务，或查看记忆。使用 DSH 会话时沿用宿主的模型配置。

每位伙伴使用独立记忆库。爱之屋关闭时可继续交谈，开启后插件会尝试恢复连接并同步待写入的记忆。连接状态可在记忆设置查看。可选云办公服务器在「插件设置」中配置。

## 日常陪伴与屏幕使用情况

「插件设置 → 日常陪伴」可管理主动来信、场景弹幕和员工 API 写信。清醒且空闲的伙伴每天合计最多发三条私信，点场景顶部的弹幕即可回复。启用独立 API 写信后，该员工的人设和近期私聊会交给其模型，可能消耗模型额度。

「屏幕使用情况」默认关闭。开启后可预览最近 15 分钟的前台应用名和时长，再按伙伴授权。仅在你主动发送普通私聊时，所选伙伴才收到这份摘要。关闭后本机临时统计立即清空。

## 版本更新、收藏和备份

进入 Luma 时会检查 GitHub 上的私有正式发布，检测到新版会出现提醒。也可在「插件设置 → 版本更新」中手动检查。请使用已登录且有仓库权限的 GitHub CLI。安装更新沿用同一 DSH 档案即可继承收藏、房间与会话。

「收支记录」可以重看开包，「我的卡册」可按最近获得排序。「插件设置」可导出收藏与设置。会话与员工记忆在对应的 DSH 档案及爱之屋中。升级时保留原档案即可。要移除插件，请在 DSH 插件管理中停用或卸载。

# Luma 星伴办公室

Luma 0.6.4 适用于 Windows 上的 DeepSeek Harness Desktop。首次使用 DSH 时先打开一次桌面客户端，让 DSH 建立桌面档案。安装器通过本机 DSH 的插件命令注册本目录。在 DSH 的「插件 → 添加插件 → 安装第三方插件」中选择包含本文件的目录并启用。以后打开 DSH，从侧栏进入「Luma 办公室」。DSH 会引用此目录，移动插件时需重新指定位置。

## 协作工作室与角色记忆

点联系人或群聊标题旁的铅笔，可以给员工写备注、修改工作室名称。联系人支持按原名或备注搜索。私聊、派工和群聊的输入框随文字增高，删减后会缩回。从「收藏 → 伙伴与空间」可以直接联系已入职伙伴。

打开「联系」后，私聊顶部有「模型」「工作区」「设置」三个入口。已经绑定模型的角色会在第一个入口显示模型名。点「模型 → 本机订阅」可以直接使用本机客户端；「设置」里可以调整人格、管理记忆和切换历史会话。输入栏的公文包用于派工，加号可添加附件或选择其他协作方式。

在「联系 → 新建工作室」选择至少两位已入职伙伴。第一位担任协调人，负责拆解本轮任务、收集成员交付并汇总。成员可并行工作，也可以点名请同事协查。需要按先后顺序交接时，选择「顺序接力」。每位成员的模型可在「成员与分工」或「插件设置 → 角色与模型」配置。

已有 Codex 登录的电脑，可以在「插件设置 → 本机 Harness」点「重新检测」，选择角色、账号可用的模型和思考强度，再绑定给角色。聊天和派工都会调用本机官方客户端，使用该账号的额度。Claude Code 也有适配入口，实际可用性取决于本机 CLI 及其登录状态。迁移到另一台电脑时，请先在对应的官方客户端登录，再到此处检测。插件设置备份不包含订阅凭证。

在私聊或工作室的对话页头点「工作区」。选「屏幕」可预览指定应用窗口，选「浏览器」可看指定浏览器的画面和页面文字。需要操作时，再把窗口分配给这次派工的成员。「数据」显示成员模型和任务进度，「文件」可按步骤导出成员交付的 Markdown。已配置云办公服务的用户可以从工作区底部打开角色的云电脑。

派工时展开「本次电脑操作」，可给每位成员选择一个 Windows 应用窗口。不同窗口可同时操作；同一个窗口会排队交接。插件使用随包的 agent-desktop 读取目标窗口的辅助功能控件，执行点击、填写、勾选或展开，并回读结果。每次派工重新选择窗口。像素画布、独占全屏游戏等缺少可访问控件的界面不适用。

在「插件设置 → 角色记忆」选择伙伴，可查看、更正或移除她眼中的用户画像。私聊和单人任务共用个人画像，每个工作室另有本群可见的画像。角色会整理明确的长期偏好；绑定模型后，可选择每四轮由该模型补充归纳。删除已结束的工作后，可以单独管理保留的画像。设置中的 JSON 备份覆盖插件偏好和收藏，迁移工作与画像时另需备份 DSH 档案。

## 拖动伙伴与桌面探头

在办公室拖动伙伴时，场景会提示目标工位和需要换位的同事。在个人 DSH 中，看到换座成功的提示后，重开仍会保留两人的工位。放在地面可以让伙伴停留片刻。八位伙伴有各自的办公日常和散步偏好，第一次短休也会错开。

点「纸飞机」，再点一位在场的伙伴，就能拿到她的回笺和邮戳。点「再传一位」可以接力，点「收回纸飞机」结束。卧室里，清醒空闲时可以点床边的手机或书桌的电脑邀请伙伴；她会沿房间地面走过去，坐好或躺下后与你分享，随后接回自己的作息。

打开「员工列表」，点击伙伴的头像或名字即可进入她的卧室。名册里的「换装」可打开这位伙伴的衣橱，点击星币进度可查看用量明细。场景底部的「换肤」用于切换房间主题。

按住伙伴直接拖动，松开后她会在可走的地面稍作停留，再接回自己的活动。在办公室里，把伙伴拖到亮起的工位后松手即可换座。选到另一位伙伴的工位时，两人交换位置，正在处理的任务会继续。

在窗口模式下，把伙伴拖过 DSH 的外边缘再松手，她会出现在鼠标所在的显示器。也可以从「员工列表」点角色旁的「桌宠」。白天轻点可打个招呼，午休时伙伴会歇一会儿。待机时伙伴双脚站稳，轻轻抬手，原画中睁开的眼睛会随鼠标转动。抓起时她会抬手收脚。上下拖动时小腿和衣袖会跟进，斜拖后突然反向时裙摆和发梢会稍晚一些摆过去。停手后她会稳住，松手时从当前姿态落地，屈膝后再站稳。把伙伴拖到当前显示器工作区的任一边缘松手，她会留在边缘探头。点击露出的部分或把她拖回桌面中央即可返回。夜里召唤时，她会带着困意回应你，过一会儿靠到屏幕底边打盹。轻点可以唤她回应，也可以随时拖动。右键选择「回到房间」或在名册点「回到场景」后，她会按当前作息回到办公室或卧室。

## 场景和爱之屋快捷连接

在 DSH 左栏点「Luma 办公室」，房间会铺满独立页面。场景左上角的侧栏按钮可随时展开或收起 DSH。点左上角带波纹标志的「Luma 星伴」可打开菜单，进入联系、收藏、卡包商店、插件设置或返回 DSH。宽窗口可直接使用旁边的联系、收藏和设置快捷入口。在联系、卡册、商店及设置的页头点「返回场景」，会回到刚才的房间。场景内可直接切换办公室和伙伴卧室，管理已拥有的房间与衣装。窄窗口可拖动画面，点「查看全景」可一次看全房间。「隐藏场景按钮」可暂时只看场景。

点击场景左上角「爱之屋」，再点连接按钮。面板会核对本机爱之屋的服务版本和每位员工的独立记忆库。本版已验证爱之屋 0.10.7rc1。如果旧版正在使用同一数据目录，请先在爱之屋中正常退出，再在插件中启动新版。已有自定义数据目录可在连接面板中选择。下载见[爱之屋官方发布页](https://github.com/myflww/love-house/releases/tag/v0.10.7rc1)。

## 从鲸鱼娘开始

全新 DSH 档案从鲸鱼娘、普通办公室和普通卧室开始。每位新入职的伙伴都有一间普通卧室。包括鲸鱼娘在内，集齐对应伙伴的全部正版卡面后，才会解锁她的主题办公室和卧室。打开「我的卡册」时持有卡片和已开卡包均为零。「卡池图鉴」可查看各包的收录范围。「办公室」显示当前班次，伙伴按本地时间在办公室或卧室活动。打开员工列表即可进入伙伴卧室、换装或带出桌宠，在卧室里点「联系」可发消息。角色专属主题的解锁进度可在「伙伴与空间」查看。工作日 09:00–12:00 和 13:00–18:00 上班，中午在办公室休息。有待办时伙伴仍可留在工位。清闲时 20:00 就寝、06:00 起床。办公室为八位伙伴分别保留工位。到班后，她们会走到各自的电脑前，在敲键盘、查看屏幕与核对工作之间切换。回到卧室后，伙伴会在房间里走动，也会坐到电脑前或躺在床上看手机。

进入「菜单 → 卡包商店」，领取新册礼，用本地星币购买卡包，再到未开封卡包中拆包。得到可兑换的卡片后，可在开包结果中邀请该伙伴，也可以稍后到「卡牌收藏 → 伙伴与空间」办理入职。只有确认兑换时才消耗选中的一张具体卡片。每位伙伴的页面都列出对应卡包、可兑换版本与空间收集进度。集齐某位伙伴的全部正版卡面，可永久解锁她的专属办公室和卧室。免费拆包体验只用于预览。

打开办公室或卧室的「员工列表」，每位伙伴右侧显示下一枚星币的进度。点她的姓名可以展开联系、卧室、换装、工位和桌宠操作。在「菜单 → 卡包商店 → 员工用量」可查看详细账本。用量按模型返回的记录计入对应伙伴。每人每满 100 万 token，钱包自动增加 1 星币，余量继续累计。旧档可回填能确认归属、且留有用量记录的 DSH 会话。独立 API 的用量从 0.5.3 起按服务返回的记录累计。旧版装帧商店已下架，升级后会按购买记录中的实付金额自动退还星币。

「卡包商店 → 卧室皮肤」提供六款可永久使用的通用卧室。蔷薇画房、宝蓝琴房、雪原书斋各需 120 星币，山茶花亭、蓝晶蔷薇廊、霜蝶玻璃馆各需 180 星币。商店和卧室的「换肤」都能免费预览日景与夜景。每款购买一次，即可在多位伙伴的卧室中同时使用。

## 联系与记忆

在「联系」选择已入职的伙伴，输入消息即可聊天。可以给一位伙伴派工，也可以选择多位已入职的伙伴建立协作群。每位伙伴分别保存设置与聊天记录。在对话设置中可调整人格、查看记忆，或打开「API 服务」。默认使用 DSH 会话。也可以给当前伙伴指定 DSH 已配置的服务、模型和可用的思考强度，或添加兼容 Chat Completions、Anthropic Messages、Gemini 的自定义端点。自定义端点可读取可用模型，或手动填写模型 ID。保存后，该伙伴在私聊、单人派工和协作群中均使用所选模型。

每位伙伴使用独立记忆库。爱之屋关闭时可继续交谈，开启后插件会尝试恢复连接并同步待写入的记忆。连接状态可在记忆设置查看。可选云办公服务器在「插件设置」中配置。

在私聊、派工或群聊输入框的「＋」菜单中选择「添加图片或文件」。可以只发附件，也可以附上要伙伴完成的任务。发送前点文件名旁的 × 可移除该项。每条可附 4 个文件，实际可发送体积取决于 DSH 或所选模型服务。

DSH 默认桌面会话可直接发送 PNG、JPEG、WebP、GIF 图片，并能将 PDF、Office 文档等原文件交给当前会话的文件工具。在「API 服务」指定 DSH 模型后，可发送 UTF-8 文本及模型支持的图片。自定义 API 可接收这些图片、PDF 及 UTF-8 文本（包括 Markdown、CSV、JSON 和代码）。图片和 PDF 需要所选模型支持。群聊选「全员接力」时，每位参与员工的模型都会收到该条消息的附件。

## 日常陪伴与屏幕使用情况

「插件设置 → 通用」可管理主动来信、场景弹幕和员工 API 写信。按本机时间，伙伴可在 08:30 至 20:00 前主动来信，每天合计最多三条。最近聊过天或伙伴正在忙时会延后。若写信途中进入夜间安静时段，这封信会取消。点场景顶部的来信即可回复。启用独立 API 写信后，该员工的人设和近期私聊会交给其模型，可能消耗模型额度。

「屏幕使用情况」默认关闭。开启后可预览最近 15 分钟的前台应用名和时长，再按伙伴授权。仅在你主动发送普通私聊时，所选伙伴才收到这份摘要。关闭后本机临时统计立即清空。

## 版本更新、收藏和备份

进入 Luma 时会检查 GitHub 上的正式发布，检测到新版会出现提醒。也可在「插件设置 → 版本与帮助」中手动检查。安装更新沿用同一 DSH 档案即可继承收藏、房间与会话。

插件界面跟随 DSH 的浅色、深色和系统外观。卡册中的卡片在白色展台上旋转；喜欢、评分、备注和收藏夹仍用于整理自己的收藏。

「收支记录」可以重看开包，「我的卡册」可按最近获得排序。「插件设置」可导出收藏与设置。会话与员工记忆在对应的 DSH 档案及爱之屋中。升级时保留原档案即可。要退回上一版，关闭 DSH，运行本版安装器 `Get-Luma-DSH.ps1 -Rollback`，再重新打开 DSH。也可以通过 `-Base` 指定保留的旧版完整目录。要移除插件，请在 DSH 插件管理中停用或卸载。

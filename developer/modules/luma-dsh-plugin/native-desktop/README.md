# Luma 星伴办公室

适用于 Windows 版 DeepSeek Harness 桌面端 0.2.2-rc.1。

在 DeepSeek Harness 的「插件」里选择「添加插件 → 安装第三方插件」，输入本插件文件夹的完整路径。启用后从左侧进入 Luma。日常使用直接打开 DeepSeek Harness。

在办公室打开员工列表，可以选择同事、进入卧室或打开工作台。在工作台可单独交谈、分配任务或发起协作。员工可以各自设置兼容 Chat Completions 的服务、模型和人格。卡册与本地星币卡包在收藏页。

在「卡包与装帧 → 收支记录」点「重看开包」可回看当天或更早获得的卡片。「卡牌收藏 → 我的卡册」的排序支持「最近获得」。独立服务暂时离线时，在工作台选择 DSH 会话可继续聊天或派工。

当前桌面档案有独立的员工工作台与记忆。如果这台电脑的 Luma 便携版已经绑定八个员工库，可以在记忆面板选用原有库。打开爱之屋后，插件会逐一核对角色与库，再同步新的记忆。也可以为桌面档案另建一套库。模型请求使用你为员工选择的服务。

需要移除入口时，在 DeepSeek Harness 的插件管理中停用或卸载 Luma。

从本地目录安装后，DSH 会引用该目录。移动文件夹前请先卸载，移动完成后再用新路径安装。

# Luma 星伴办公室

Luma 0.6.0 适用于 Windows 上的 DeepSeek Harness Desktop。首次使用 DSH 时先打开一次桌面客户端，让 DSH 建立桌面档案。安装器通过本机 DSH 的插件命令注册本目录。在 DSH 的「插件 → 添加插件 → 安装第三方插件」中选择包含本文件的目录并启用。以后打开 DSH，从侧栏进入「Luma 办公室」。DSH 会引用此目录，移动插件时需重新指定位置。

## 拖动伙伴与桌面探头

按住伙伴直接拖动，松开后她会在可走的地面稍作停留，再接回自己的活动。办公室里，把伙伴放到亮起的椅子即可重新绑定工位；也可以在「员工列表」中选择工位。选到另一位伙伴的工位时，两人交换位置，正在处理的任务会继续。

在窗口模式下，把伙伴拖过 DSH 的外边缘再松手，她会出现在鼠标所在的显示器。全屏或使用键盘时，在「员工列表」点「桌宠」也可以带她出来。把桌宠拖到屏幕左边或右边松手，可以看到她从边缘探头、停留，再缩回去。点击探出的部分可将她拉回桌面。右键选择「回到房间」或在员工列表点「回到场景」，她会按当前作息回办公室或卧室。到了睡眠时段，桌宠也会安睡。

## 场景和爱之屋快捷连接

在 DSH 左栏点「Luma 办公室」，房间会铺满独立页面。场景左上角的侧栏按钮可随时展开或收起 DSH。点左上角带波纹标志的「Luma 星伴」可打开菜单，进入联系、收藏、卡包商店、插件设置或返回 DSH。宽窗口可直接使用旁边的联系、收藏和设置快捷入口。在联系、卡册、商店及设置的页头点「返回场景」，会回到刚才的房间。场景内可直接切换办公室和伙伴卧室，管理已拥有的房间与衣装。窄窗口可拖动画面，点「查看全景」可一次看全房间。「隐藏场景按钮」可暂时只看场景。

点击场景左上角「爱之屋」，再点连接按钮。面板会核对本机爱之屋的服务版本和每位员工的独立记忆库。本版已验证爱之屋 0.10.7rc1。如果旧版正在使用同一数据目录，请先在爱之屋中正常退出，再在插件中启动新版。已有自定义数据目录可在连接面板中选择。下载见[爱之屋官方发布页](https://github.com/myflww/love-house/releases/tag/v0.10.7rc1)。

## 从鲸鱼娘开始

全新 DSH 档案从鲸鱼娘、普通办公室和普通卧室开始。每位新入职的伙伴都有一间普通卧室。包括鲸鱼娘在内，集齐对应伙伴的全部正版卡面后，才会解锁她的主题办公室和卧室。打开「我的卡册」时持有卡片和已开卡包均为零。「卡池图鉴」可查看各包的收录范围。「办公室」显示当前班次，伙伴按本地时间在办公室或卧室活动。打开员工列表可找人、进入房间或发消息。换肤面板显示已获得且有对应美术的主题，可在「伙伴与空间」查看解锁进度。工作日 09:00–12:00 和 13:00–18:00 上班，中午在办公室休息。有待办时伙伴仍可留在工位。清闲时 20:00 就寝、06:00 起床。办公室为八位伙伴分别保留工位。到班后，她们会走到各自的电脑前，在敲键盘、查看屏幕与核对工作之间切换。回到卧室后，伙伴会在房间里走动，也会坐到电脑前或躺在床上看手机。

进入「菜单 → 卡包商店」，领取新册礼，用本地星币购买卡包，再到未开封卡包中拆包。得到可兑换的卡片后，可在开包结果中邀请该伙伴，也可以稍后到「卡牌收藏 → 伙伴与空间」办理入职。只有确认兑换时才消耗选中的一张具体卡片。每位伙伴的页面都列出对应卡包、可兑换版本与空间收集进度。集齐某位伙伴的全部正版卡面，可永久解锁她的专属办公室和卧室。免费拆包体验只用于预览。

打开办公室或卧室的「员工列表」，每位伙伴右侧显示下一枚星币的进度。点她的姓名可以展开联系、卧室、换装、工位和桌宠操作。在「菜单 → 卡包商店 → 员工用量」可查看详细账本。用量按模型返回的记录计入对应伙伴。每人每满 100 万 token，钱包自动增加 1 星币，余量继续累计。旧档可回填能确认归属、且留有用量记录的 DSH 会话。独立 API 的用量从 0.5.3 起按服务返回的记录累计。旧版装帧商店已下架，升级后会按购买记录中的实付金额自动退还星币。

## 联系与记忆

在「联系」选择已入职的伙伴，输入消息即可聊天。可以给一位伙伴派工，也可以选择多位已入职的伙伴建立协作群。每位伙伴分别保存设置与聊天记录。在对话设置中可调整人格、查看记忆，或打开「API 服务」。默认使用 DSH 会话。也可以给当前伙伴指定 DSH 已配置的服务、模型和可用的思考强度，或添加兼容 Chat Completions、Anthropic Messages、Gemini 的自定义端点。自定义端点可读取可用模型，或手动填写模型 ID。保存后，该伙伴在私聊、单人派工和协作群中均使用所选模型。

每位伙伴使用独立记忆库。爱之屋关闭时可继续交谈，开启后插件会尝试恢复连接并同步待写入的记忆。连接状态可在记忆设置查看。可选云办公服务器在「插件设置」中配置。

在私聊、派工或群聊输入框的「＋」菜单中选择「添加图片或文件」。可以只发附件，也可以附上要伙伴完成的任务。发送前点文件名旁的 × 可移除该项。每条可附 4 个文件，实际可发送体积取决于 DSH 或所选模型服务。

DSH 默认桌面会话可直接发送 PNG、JPEG、WebP、GIF 图片，并能将 PDF、Office 文档等原文件交给当前会话的文件工具。在「API 服务」指定 DSH 模型后，可发送 UTF-8 文本及模型支持的图片。自定义 API 可接收这些图片、PDF 及 UTF-8 文本（包括 Markdown、CSV、JSON 和代码）。图片和 PDF 需要所选模型支持。群聊选「全员接力」时，每位参与员工的模型都会收到该条消息的附件。

## 日常陪伴与屏幕使用情况

「插件设置 → 通用」可管理主动来信、场景弹幕和员工 API 写信。清醒且空闲的伙伴每天合计最多发三条私信，点场景顶部的弹幕即可回复。启用独立 API 写信后，该员工的人设和近期私聊会交给其模型，可能消耗模型额度。

「屏幕使用情况」默认关闭。开启后可预览最近 15 分钟的前台应用名和时长，再按伙伴授权。仅在你主动发送普通私聊时，所选伙伴才收到这份摘要。关闭后本机临时统计立即清空。

## 版本更新、收藏和备份

进入 Luma 时会检查 GitHub 上的私有正式发布，检测到新版会出现提醒。也可在「插件设置 → 版本与帮助」中手动检查。请使用已登录且有仓库权限的 GitHub CLI。安装更新沿用同一 DSH 档案即可继承收藏、房间与会话。

「收支记录」可以重看开包，「我的卡册」可按最近获得排序。「插件设置」可导出收藏与设置。会话与员工记忆在对应的 DSH 档案及爱之屋中。升级时保留原档案即可。要退回上一版，关闭 DSH，运行本版安装器 `Get-Luma-DSH.ps1 -Rollback`，再重新打开 DSH。默认会重新注册桌面 `Luma-DSH` 中保留的 `DesktopPlugin-0.5.4`，可通过 `-Base` 指定其他旧版完整目录。要移除插件，请在 DSH 插件管理中停用或卸载。

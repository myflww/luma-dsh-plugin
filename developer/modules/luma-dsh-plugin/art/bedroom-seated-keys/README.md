# 卧室坐姿原画

14 套造型每套分别绘制两种朝右前方伸手打字的坐姿。本目录是较侧面的视角，约 60 度。[quarter](quarter) 是较靠后的视角，约 40 度。角度以正后方为零度。每张透明 PNG 包含四张原画，手指轮换触键，鞋尖有轻微变化。绘制时逐套参考角色招呼画的发饰、肤色、轮廓、衣装和鞋，以及蔷薇画房、雪原书斋联合原画中的头身、坐深和鞋底大小。[角色招呼与动作参照](../actor-poses-keys) · [房间人椅合绘](../desk-q-keys/joint)

两个目录各有一份 `registration.json`。每行的 16 个数均使用第一格人物紧边界上的百分坐标，顺序为颅骨后缘与前缘的横坐标、颅顶与下巴的纵坐标、坐骨承重点、远侧指尖、近侧指尖、肘、膝盖和鞋底。后六项各含横、纵坐标。长发、犄角、光环和外露饰件可超出颅骨范围。[联合原画头宽标定](joint-skull-landmarks.json) 单独记录两个示范房中各套造型的颅骨前后缘。

构建程序将人物等比缩放至统一头宽，以坐骨对齐源格。前臂和小腿分别采用四格相应区域。房间渲染时按椅子的透视和实际键盘确定人物、手肘和双手位置，保留椅面、扶手与桌前缘遮挡。每个房间的夜间着色根据同一把椅子的昼夜像素测量。[图集编译脚本](../../scripts/prepare-bedroom-seated.py) · [开发与重建步骤](../../../../README.md)
